# Sources and licenses for embedded assets

All fonts and icons are embedded inside each SVG, so nothing is loaded from the network.

## Fonts (SIL Open Font License 1.1, license texts in this folder)
- **Bebas Neue** (display), by Dharma Type. Latin subset WOFF2 from the npm package `@fontsource/bebas-neue`. License: BebasNeue-OFL.txt
- **JetBrains Mono** (mono), by JetBrains. Latin subset WOFF2 from the npm package `@fontsource/jetbrains-mono`. License: JetBrainsMono-OFL.txt

## Icons (CC0 1.0, Simple Icons v13.21.0, https://simpleicons.org, npm `simple-icons@13.21.0`)
Python, FastAPI, LangChain, PostgreSQL, Docker, Redis, Flask, Git, Celery, Pydantic, SQLite (stack orbits); LinkedIn, LeetCode, GitHub (connect cards).
Version 13.21.0 is pinned because later Simple Icons releases removed some brand marks (LinkedIn among them). Brand marks remain trademarks of their owners and are used only to identify the linked services and technologies. License: SimpleIcons-CC0.txt

## Images
`id.png` and `right_pointing.png` are the owner's own generated portraits, resized for embedding with their alpha channel kept.
